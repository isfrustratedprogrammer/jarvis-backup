jarvis-backup

jarvis-backup is a personal backup tool used by a single person for their own home server. It runs rclone and restic to store encrypted backups of that person's own data in their own Google Drive.

It is not offered to anyone else, has no other users and no web interface.

Google Drive access uses only the drive.file scope: the tool can see and change only the files it created itself.
